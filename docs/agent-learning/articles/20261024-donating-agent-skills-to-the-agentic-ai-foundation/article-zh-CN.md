## AI 导读

文章围绕 Agent Skills 技能标准将由谁承接展开。作者引用 Anthropic 公告，称其正将标准捐赠给 Linux 基金会旗下的代理式人工智能基金会，并表达保持开放、社区驱动和厂商中立的承诺。作者随后回顾自己此前对这一归属的预测，并提到通过 Claude 检索博客找回旧文的经历。正文主要传递标准归属的消息，没有说明技能标准如何工作、捐赠后的决策机制或实施安排；开放与厂商中立仍是公告中的承诺，材料不足以判断实际治理效果。

## 原文整理

2026 年 10 月 22 日 — 链接博客

**[将 Agent Skills 捐赠给代理式人工智能基金会](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)**。Anthropic 今天发布的消息：

> 我们致力于让 Agent Skills 保持开放、由社区推动，并保持厂商中立。今天，我们将这一标准捐赠给 Linux 基金会旗下的代理式人工智能基金会（AAIF）。该基金会由我们与 Block、OpenAI 于去年[共同创立](https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation)，我们也已将模型上下文协议（MCP）捐赠给该基金会。

很高兴看到，我在[去年 12 月](https://simonwillison.net/2025/Dec/19/agent-skills/)就预料到了这一点。当时 Anthropic 首次宣布 skills 是一项“开放标准”，我写道：

> 如果它最终[归入 AAIF](https://simonwillison.net/2025/Dec/9/agentic-ai-foundation/)，我不会感到意外。MCP 规范最近也刚归入这个基金会。

顺便说件有趣的事：Claude 可以通过 [datasette-mcp](https://github.com/datasette/datasette-mcp) 插件访问我的博客内容，所以我通过[向 Claude 提示](https://claude.ai/share/80b341de-590b-4834-bca9-0d9c9a3a0298)找到了那篇文章，提示内容是：“`使用 simonwillison.net MCP，查找我是否曾谈到过希望将 skills 捐赠给某个标准组织。`”
